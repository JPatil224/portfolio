# Jayanti Patil Portfolio — refreshed design

## Update your existing GitHub Pages website
1. Download and unzip this package.
2. Open your existing `portfolio` repository on GitHub.
3. For each of `index.html`, `style.css`, and `script.js`, upload the new version and commit the changes (or replace the old files).
4. Your existing GitHub Pages settings should publish the update automatically after a few minutes.
