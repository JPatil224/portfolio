# Jayanti Patil — Portfolio

This is a static portfolio website for GitHub Pages.

## Files
- `index.html` — main portfolio
- `style.css` — responsive styling
- `script.js` — smooth navigation

## Publish on GitHub Pages
1. Create a GitHub repository named `portfolio`.
2. Upload these three files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Your site should appear at:
   `https://jpatil224.github.io/portfolio/`

Before submitting, replace/add any missing certification links and your resume PDF if desired.
